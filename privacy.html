Nightwatch Backup 隐私与数据使用说明

更新日期：2026-11-01

用途与访问范围

本应用仅供账号所有者自用，将运行数据加密备份到其 Google Drive，并在必要时下载、校验和恢复。Google OAuth 只请求 https://www.googleapis.com/auth/drive.file，访问本应用创建或用户明确授权的文件，不请求整个网盘、邮件、联系人或日历。

数据与保存

备份文件由 Restic 在上传前加密。备份程序处理加密对象及其文件元数据，以完成上传、完整性校验和恢复。OAuth 令牌与客户端凭据保存在所有者控制的服务器受保护文件中；它们不写入公开网页或普通运行日志。备份解密密钥独立保存，不随备份内容上传。

使用与共享

这些数据仅用于本人备份与恢复，不出售、不用于广告、不共享给其他用户，也不用于训练或改进通用人工智能模型。传输使用加密连接；Google Drive 按其自身服务政策存储加密备份。本公开说明页不包含私人账户或交易数据。

保留与撤销

备份保留由所有者的配置和存储空间决定。当前程序不自动永久删除远端备份。所有者可在 Google 账号的第三方访问管理中撤销本应用授权，并在 Google Drive 中自行删除备份；撤销授权后自动备份会停止。服务器凭据和本地恢复材料由所有者自行管理。

联系与政策

问题或删除请求可联系 Google 授权页面显示的应用支持邮箱。对 Google API 数据的使用遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。
